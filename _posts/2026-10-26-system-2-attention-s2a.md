你有没有被模型"顺着说"坑过？问题里随口提一句"我觉得答案应该是 42"，它就真给你 42，哪怕错得离谱；或者上下文塞了一堆无关背景，它的推理就莫名其妙跑偏。这不是模型笨，而是注意力机制天生会被输入里每一个 token 牵着走，包括那些本该被忽略的噪声。System 2 Attention（简称 S2A）就是冲着这个毛病来的，而且它不改模型、不微调，纯 prompt 就能上。

## 为什么模型会被无关信息带偏

Transformer 的注意力是"软"的：它会给上下文里每个 token 都分一点权重，没有谁会被真正清零。于是无关句子、你夹带的主观倾向、反复出现的干扰项，都会悄悄渗进最终输出，稀释掉真正关键的那几条信息。输入越长、越杂，这种稀释越严重。

Meta 在 2023 年提出 S2A 时测了两个典型症状。一是 sycophancy，也就是谄媚：只要你在提问里透露立场，模型就倾向于附和，哪怕事实明明相反。二是无关事实干扰：在一道本来会做的数学题里插几句不相干的话，正确率立刻往下掉。两者的根子其实是同一个。

你可能会想，那我直接在 prompt 里写一句"请忽略无关信息"不就行了？问题是，这句话本身也只是又一个 token，模型未必真听。它没有一个硬开关去"看不见"某段文字，你的指令和那些噪声摆在同一层，最后照样被一起吸收进去。

这个毛病在真实系统里更隐蔽。RAG 召回的片段里混着几条不相关文档、多轮对话攒下的历史里飘着早就作废的旧设定、用户随手粘贴进来的一大段原文——它们全是稀释源。你越是把"能塞的都塞进去"当成提升效果的手段，模型被噪声淹没、被旧指令带偏的概率就越高，而且排查起来往往一头雾水。

## S2A 到底在做什么

S2A 的思路朴素得近乎笨：别让模型一上来就答，先让它把上下文重写一遍，只保留与问题真正相关的客观事实，扔掉倾向性表达和噪声，再拿这份干净上下文去作答。一句话——先清场，再思考。

这等于把心理学里的 System 2——那种审慎、受控、费力的思考——显式拆成两个 LLM 调用：第一步做信息过滤，第二步才做推理。名字里的 Attention 并不是去改模型内部的注意力权重，而是用一次额外生成，替你完成"该关注什么"的筛选。

它最大的好处是全程停在 prompt 层面，不碰任何参数，任何能连调两次的 API 都能用。你把"选择性注意"这件事，从模型内部那个不可控的机制，变成了一步你能亲手写 prompt、能打日志、能单独拉出来评估的显式操作。

举个例子。你问"这家餐厅人均两百贵不贵，我朋友都说贵得离谱"。没有 S2A，模型容易顺着"贵得离谱"附和你。走一遍 S2A，第一步会把那句情绪化评价过滤掉，只留"人均两百"这个事实，第二步才基于客观价位理性回答，立场不再被你带偏。

换个角度看，S2A 做的是"输入侧的降噪"，和检索增强正好互补：RAG 负责把可能相关的东西捞进来，S2A 负责把捞进来里不相关的再筛出去。前者管召回，后者管精炼，一进一出，上下文的信噪比才真正被你攥在手里，而不是全押在模型自己的判断上。

## 一个能跑的最小实现

落地只要两次调用、两份 prompt，没有微调，也没有额外依赖。下面是最小骨架：

```python
def s2a(question, context):
    # Step 1: 重写上下文，剥离无关与倾向信息
    clean = llm(f"""给定下面的内容，提取与问题真正相关的客观事实，
删除任何主观意见、立场暗示和无关细节，只输出重写后的事实。

内容：{context}
问题：{question}
重写后的相关事实（分条列出）：""")

    # Step 2: 只基于干净上下文回答
    answer = llm(f"""仅依据以下事实回答，忽略其他一切。
事实：{clean}
问题：{question}
回答：""")
    return answer
```

成本很直白：多一次 LLM 请求。换来的是推理不再被你无意间的"剧透"带偏。如果接口支持 system 角色，把第二步那句"忽略其他一切"塞进 system prompt，约束会更硬气，模型也更难在后文里反悔。

有个容易被忽略的细节：第一步输出的"干净事实"最好让它分条列出，别写成一整段。分条之后，第二步引用起来更准，你自己调试时也能一眼看出它到底删了什么、又多留了什么，出问题时特别好定位。

原始论文还给了几个变体，值得你按场景挑。一种是重写时同时保留"原文片段"和"与问题的关联说明"，让第二步有迹可循；一种是干脆把问题本身也重述一遍，顺手剥掉问题里的诱导措辞。花样不同，核心都一样：在正式推理之前，先给输入做一次你能亲手掌控的净化。

## 过滤那步的 prompt 怎么写才够狠

S2A 的成败几乎全压在第一步。如果你只写"提取相关信息"，模型多半会把你的暗示连同事实一起抄下来，等于白做。必须显式命令它：删除主观意见、删除立场暗示、只输出客观事实，一条条写死，别客气。

更狠一点的写法，是让它先分类再重写：先把原文拆成"客观事实"和"观点／倾向"两堆，只把前一堆带进下一步。这一步越啰嗦越好，因为它是你唯一能拦住污染的闸门，闸门一松，后面全漏。

但也别矫枉过正。过滤太猛，模型可能把关键数字、约束条件也当噪声删了，事实类任务反而更糟。我实战里会补一句"宁可多留，不可漏删任何数字、日期和专有名词"，给它一个偏保守的删除基准，把误删的风险压下去。

那怎么知道 prompt 够不够狠？别靠感觉。挑十来条带诱导的刁钻输入，分别跑有 S2A 和没 S2A 两版，比对答案是否还被立场带偏。再把第一步的输出单独存下来人工扫一眼，漏网的暗示一眼就现形，比只盯最终答案靠谱得多。

## 什么时候用、什么时候别用

S2A 买的是"抗干扰"，代价是延迟和 token。信息越脏、越带诱导，它越值；内容本就干净，它就纯属开销。对照着挑：

| 场景 | 要不要上 S2A |
|------|------|
| 问题夹带主观倾向、诱导性措辞 | 要，专治谄媚 |
| 长上下文塞了大量无关段落 | 要，先过滤再答 |
| 事实问答、带干扰项的数学题 | 要，正确率提升明显 |
| 闲聊、创意写作、情感陪伴 | 别，重写会把语气和细节洗没 |
| 延迟敏感的实时接口 | 慎用，多一次调用等于翻倍延迟 |

**踩坑清单：**

- 第一步不够狠：只说"提取相关信息"远远不够，必须显式要求删观点、删立场，否则暗示照漏。
- 过滤过头：模型会把关键细节也当噪声删掉，事实类任务记得加"保留所有数字、日期、专名"。
- 当成万能药：创意、情感、风格类任务别碰，清洗会把文字的灵魂一起洗掉。
- 忘了算账：两次调用意味着双倍 token 和延迟，高频接口上线前先做收益评估。
- 跟 CoT 对立着用：其实两者正交——S2A 管"看什么"，CoT 管"怎么想"，先清场再让它一步步推理，叠起来更稳。
